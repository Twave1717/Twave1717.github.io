I'm interested in AI that learns from the people it works with. Instead of a model that knows everything, I want to build agents that deeply understand one person's work (their projects, decisions and context) and keep improving from it. A central question for me is how to separate the working memory worth learning from information that should stay private.

About Me

I'm currently a research intern at the Efficient Learning Lab at Sungkyunkwan University, advised by Prof. Hankook Lee. Through the undergraduate research program (URP), I'm working on fusing chart images with time-series inputs to improve performance on TSRBench.

Beyond the lab, my long-term vision is self-evolving AI agents: agents that continually learn a person's working memory and grow alongside them, from a single project to an entire career. As a first step, I'm building AI agents that help academic clubs run their projects, aiming for a system that automatically builds up a club's knowledge as an ontology. So far this includes a curriculum agent that designs club curricula from real job postings and a FactChecker that helps clubs verify what candidates claim in interviews. Alongside these, I'm studying how teams and individuals can build working memory efficiently, so that knowledge accumulates on its own and the next generation can build on it.

My interests include:

  • Self-Evolving AI Agents: agents that learn a person's working memory over time, from projects to an entire career.
  • Time-Series Chart Understanding: how multimodal models read and understand time series rendered as charts (TSRBench).
  • Efficient Adaptation: few-shot adaptation of vision-language models.
